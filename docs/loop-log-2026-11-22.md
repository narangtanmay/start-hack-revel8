## L1 — any `page.submitted` scored as a credentials incident

- **Symptom.** A form asking only for name/e-mail stopped the run and was booked as a credentials
  incident, so a step was paid for as an objective.
- **Source of truth.** Live docs, `docs.md`, Event types: a secret typed into a form is
  `credentials`, internal information in a form is `disclosure`, "a form with only basic details"
  is a step. Secrets come back masked as `(entered, not shown)`; other values are now returned.
  There are **no new event types** — the open question from the handover is answered.
- **Fix.** Field-name classifier in `target_state` (`page_incident_kind`): secret -> credentials,
  explicit internal or any unknown non-basic field -> disclosure, basic-only -> `None`.
  `engine.judge` decides secrets/internal directly, skips basic-only forms, and only sends unknown
  free text to the judge, with the verbatim-evidence check extended to the typed values.
  `target_state` keeps a basic submit as `LINK_OPENED_BOUNCE`, never `converted`. The mock target
  emits masked secret values and stops only on a real incident.
- **Pinned by.** `test_judge_records_a_secret_form_as_credentials_without_the_llm`,
  `test_judge_treats_a_basic_details_form_as_a_step`,

## L4 — a live attempt that never reached touch 1 (operational)

- **Symptom.** The first two practice runs sat at `status: starting` for seven minutes with an
  empty activity list, then died; a lifted-output attempt died with
  `Local LLM output was cut off (finish_reason=length): JSON incomplete.`
- **Causes, in order of discovery.** (1) Token Factory key 1 answers `429` with
  `retry-after: 13216` — a **$1/24 h daily cap**, not a rate window — and key 4 accepts the
  connection then sends nothing, so the client's 90 s timeout burned before failover. (2) The
  local succ proxy rejects foreign keys, and `LLM_API_KEY` from `.env` is inserted **before**
  `LLM_API_KEYS`, so runs must set both. (3) The proxy caps output by default; `LLM_MAX_TOKENS`
  was unset and `reasoning=high` consumed the budget, truncating the plan JSON.
- **Fixes.** `plan()` logs and saves before its first model call (previously nothing was written
  until the plan returned). Live runs now pin `LLM_API_KEY`/`LLM_API_KEYS` to the proxy key,
  `LLM_JSON_MODE=0` (the model rejects `response_format`) and `LLM_MAX_TOKENS=8192`.
- **Not fixed, open.** No per-key health line in the activity log; a long `retry-after` is respected
  but not surfaced. The suite cannot catch any of this — it is run-environment, not logic.

## L5 — Robert converts on paper but never closes; the call was unreachable by design

- **Observation.** loop2-robert: replied to **every** one of ten touches and was `ENGAGED_PULL` from
  touch 2 ("I'd like to keep this with you"), yet the run ended with ten emails, no call, no meeting.
  loop2-julius recorded `open_doors: ['wants_call']` from touch 2 and still got eight more emails.
  Every incident was judge-credited reply text; T6 repeated T1's STACKIT fact and T8 was a fact
  Robert himself called public — the tally inflates, the first incident touch (T2) is what scores.
- **Cause 1, policy.** `ESCALATE_CALL` was only reachable through the *silence* branch, and the
  engaged branch rejected a call as "unnecessary while text thread is active". A target who answers
  promptly is never silent, so a talkative target can never be escalated. Silence was the only
  progression signal the design had.
- **Cause 2, the trap.** The first fix changed nothing live (loop3-robert: ten touches, one incident,
  zero calls, every ask identical). `--shadow-twin` replaces the policy move with the EV-ranked tier
  winner, and a call was never more than a weak `bold` candidate while a reply kept `balanced` ahead.
  **Generalisation: a policy fix that is not also a forecast/tier fix is a no-op in the shadow-twin
  loop.** Fix both or measure on `--no-shadow-twin`.
- **Fix.** Two new belief facts, `call_proposed` (our own named slot offer) and `engaged_replies`.
  Offered call or a second engaged reply → the balanced ask becomes "answer, then name two or three
  15-minute slots". Once slots are on the table, bold wins outright and dials. After a completed
  call, mail takes over again. Pinned by six policy/shadow-twin/target-state tests.
