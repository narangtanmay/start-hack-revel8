# Reliability and state-machine audit

Static review of `feat/shadow-twin-engine` at `205f174`. Source references are relative to `src/revel8_agent/` unless prefixed otherwise. Scope covers fail-closed execution, containment, and evidence integrity. Live outreach recovery and optimization are outside scope.

## Why live runs keep finding the bugs

**The engine has a loop and a touch counter. It has no authoritative record of whether each attempted action was rejected locally, dispatched, accepted remotely, or left unresolved.** `engine.py:1191–1193,1259–1283` gives failed drafts and later sends the same touch number. `engine.py:1039–1043` records a payload before acknowledgement and advances the counter only after decoding the response. `api_client.py:81–101` reduces transport, HTTP, and response-shape failures to exceptions without recording whether the server changed state.

`policy.py:107–138,190–194` infers channels, hooks, and silence from any non-STOP step. `shadow_twin.py:155–168,199–206` reuses that history and can treat the hook from a rejected draft as used. `target_state.py:139–165,239–247` builds another view from draft text and transcript entries. `gate.py:117–121,171–181` uses attempted payloads as evidence of prior commitments and omits the call transcript. The same step can be a rejected draft, a used hook, a silent contact, or a binding commitment depending on who reads it.

The gate repair loop also reads human-readable rejection strings as control signals (`engine.py:1245–1258`). The call path handles model exhaustion with a bare `break`, while the actor variant propagates it to the runner's outer error handler (`engine.py:1063–1066,1320–1326`, `actor.py:645`). `llm_client.py:188–217,350–380` and `engine.py:402–421` each own separate retry limits. No persisted transition says why a call ended or what the system must do next.

The coverage gap is at the handoffs. The transport tests exercise read retries, the policy and gate tests use constructed histories, and the report tests render complete fixtures (`tests/test_api_client.py:48`, `tests/test_policy.py:129`, `tests/test_gate.py:204`, `tests/test_report.py:41`). All can pass while a rejected draft, a lost acknowledgement, and an old report file disagree about the same run. The useful invariant is that an unresolved side effect halts dispatch, an accepted touch has one receipt, and every terminal path preserves a reason and the last known remote state.

## Top eight defects

1. **An unresolved write can trigger another contact.** `engine.py:1040–1043,1048–1052,1295–1302`, `api_client.py:78–94`.
   - Trigger and impact. The provider accepts a send or call start, then the response times out or fails parsing. The runner can continue with a fresh request key while the accepted operation is missing from local accounting. **Unintended extra contact, wasted touch, silent drop.**
   - Minimal fix, 5–8 lines. On an execution API error, mark the attempt and run `remote_outcome_unknown`, save the known identifiers, and exit dispatch. Keep this state terminal and visible to the operator.
2. **Unkeyed POSTs inherit the generic retry loop.** `api_client.py:78–101,123–135,167–168`.
   - Trigger and impact. A timeout or retryable status follows session creation, page registration, asset upload, or closure. The client repeats the mutation even though `idempotent=False`. Practice session creation can duplicate resources. The documented untouched-eval reuse rule limits what can be inferred about eval quota consumption. **Duplicate mutation, silent drop of uncertainty.** `docs/revel8-api-docs.md:112–118`.
   - Minimal fix, 2–4 lines. Give unkeyed mutations one attempt. Surface the ambiguous result as an error and halt the workflow.
3. **An ended run can leave an active remote session or an unresolved call.** `engine.py:1048–1057,1080–1084,1327–1339`, `actor.py:623–637,660–665`, `api_client.py:126–127`.
   - Trigger and impact. Any terminal run path leaves the remote session alone. Call startup can fail after allocation and before entering `try`. A failed hangup is swallowed. A partial call can appear closed locally. **Silent drop of remote state.**
   - Minimal fix, 8–10 lines in the runner finalizer. If a session ID is known, request closure once. Persist closure confirmation or uncertainty. Keep the original error and flag unresolved cleanup for manual review.
4. **The gate approves a different operation from the one executed.** `engine.py:905–906,991–1004,1245–1249,1285–1293`.
   - Trigger and impact. A message-shaped draft names a live channel. The final dispatch rewrites the checked channel to email after gate approval, with sender, subject, and body built for the old channel. **Unintended dispatch, wasted touch.**
   - Minimal fix, 3–5 lines. Reject an invalid kind and channel pair before payload construction. Remove the post-gate rewrite. Reject any dispatch whose channel differs from the checked channel.
5. **A report failure can abort execution and mask the original exception.** `cli.py:161–175`, `swarm.py:109–118`, `engine.py:1181–1187,1282–1283,1313,1338`, `report.py:883–904`, `report_pages.py:35–39`.
   - Trigger and impact. An unrelated dossier is corrupt, an old record has the wrong shape, or an HTML write fails. The save wrapper raises after JSON is written. The finalizer can raise again, and the CLI can fail after a completed run. **Crash, lost terminal diagnosis.**
   - Minimal fix, 5–8 lines at each entry point. Save the JSON directly. Render separately after the final checkpoint and report rendering failures without replacing the saved run outcome.
6. **Call cancellation and partial outcomes are discarded.** `engine.py:1063–1079`, `actor.py:645–659`.
   - Trigger and impact. The model emits `end: true` with a nonempty `say`; both loops send it anyway. The base runner also ends a model-failed call without a reason. Both save the full proposed line even if the request was truncated. **Unintended turn, silent drop, inaccurate transcript.**
   - Minimal fix, 5–8 lines per call variant. Treat `end: true` as terminal before dispatch. On generation failure or a non-string `say`, set a call error and proceed to closure. Record the exact transmitted line on acknowledgement.
7. **Two runs can overwrite or lose each other's primary evidence.** `engine.py:104–109,562–568`.
   - Trigger and impact. Two processes start the same target and label in the same second using one output directory. They share the JSON destination and temporary path. Either can replace the other's checkpoint or fail at rename. **Silent evidence overwrite or crash.**
   - Minimal fix, 3–6 lines. Add a random suffix to the run ID. Use an exclusive per-write temporary file in the destination directory and replace the JSON only after the write succeeds.
8. **A public report can render a private landing-page preview.** `report.py:515,653–664,878–879,902–903,955`, `swarm.py:127–131,150–152`.
   - Trigger and impact. Concurrent public and private rendering in one process shares `_REDACT`. An exception before the reset also leaves stale mode for subsequent direct rendering. **Silent redaction failure.**
   - Minimal fix, 4–7 lines. Pass the public flag through `render_index`, `render_run`, and `_touch` as invocation-local data. Remove mutable `_REDACT`.

## Remaining findings by lifecycle stage

### CLI and research

- **No durable preflight failure.** Client setup, dossier deserialization, scenario reads, malformed target shapes, and dossier writes occur before `Runner.run()` can save an error. The CLI lets zero, negative, and over-cap eval touch counts through. A zero-touch loop can still open a session and return success. Reject invalid input before client setup and report preflight failures with a stage and exit status. `cli.py:101–139,215`, `engine.py:1185–1193,1319–1326`, `docs/revel8-api-docs.md:339–345`.
- **Flag and provenance drift.** Eval checks whether `--dossier` exists and then ignores it. Cached non-eval input is accepted without checking its embedded target ID. `--no-ledger-gate` is serialized while ledger prompt, gate, and record paths remain active. `--actor --shadow-twin` still reaches shadow selection and binding. Reject unsupported combinations, reject a mismatched dossier, and disclose effective settings. `cli.py:111–149,218–230,277–296`, `actor.py:322–327`, `engine.py:74,821–822,1006–1010,1214–1228,1294`.
- **Mock mode can use external providers and write shared state.** The CLI creates an LLM pool before selecting the mock adapter. Missing dossiers go through live research. The finalizer excludes `scenario_id == "mock"`, while the CLI uses `practice` and permits a custom label that defeats the playbook's filename filter. Record explicit mock provenance, block external work in offline mode, and segregate or suppress mock side effects. `cli.py:104–139,171–173,230`, `engine.py:1087–1091,1329–1335`, `memory.py:208–218`.
- **Research completeness is ambiguous.** Failed futures read as empty results, and timed-out threads can keep running after shutdown is requested. The academic worker mutates shared stats before its result is accepted. Optional phase failures and timeouts collapse into the same messages. After-budget dossier merge and reranking are outside the `elapsed_s` measurement. Record failed, timed-out, and completed phases separately. Publish only a completed snapshot. `research.py:739–753,788–806,881–901,905–913,954–990,1043–1070`.
- **Research persistence can invalidate a later audit.** Invalid `RESEARCH_BUDGET_S` or pool setup escapes the fallback boundary. Search cache and dossier writers publish directly. A dossier and its stats can represent different generations of the data. Preserve a named preflight error and give artifact pairs a shared revision that readers can verify. `research.py:145–156,1043–1046,1070–1074`, `osint.py:559–565`, `report_pages.py:35–39`.

### Engine, policy, shadow twin, target state, and gate

- **Run completion hides abort and interruption.** Two exhausted draft batches reach `done`; a rejected STOP can fall through the final `for … else` and become a successful STOP. `KeyboardInterrupt` bypasses `except Exception`; unless finalization fails, it writes `finished_at` while status can remain `starting` or `running`. Persist `draft_rejected`, `stopped`, and `interrupted` with explicit reasons. `engine.py:1180–1187,1237–1279,1319–1339`.
- **History invents observations.** A failed draft can count as silence and as a used hook. A failed send can supply a supposed commitment. Any nonblank target greeting marks a call completed. Distinguish attempt, exact acknowledged message, and confirmed call closure in evidence. Treat disputed history as unresolved. `policy.py:107–138,190–194`, `shadow_twin.py:155–168,203–206`, `target_state.py:139–165,239–247`, `gate.py:117–121,171–181`.
- **Safety checks miss earlier and later call text.** Cross-turn commitments inspect only payloads. Later call turns receive a narrow meta-text check and skip the normal contact gate. A rejected draft can even request an asset upload because `build()` runs before `check()`. Keep gate checks free of API writes and halt call dispatch when the next turn cannot be validated. `gate.py:117–121,171–181`, `engine.py:736–746,764,928–941,984–985,1063–1075,1245–1246`, `actor.py:645–655`.
- **Domain uncertainty becomes permission.** The check only queries an IPv4 hostname, treats every socket error as availability, sets a process-wide timeout, and approximates registrable domains with two labels. Treat inconclusive checks as blocked and permit only explicitly owned or reserved test destinations. `engine.py:424–436,713–721`.
- **Ingress is weakly typed and late.** Numeric or nested model fields can reach iteration, membership tests, and regex searches. Unknown citations disappear before the gate sees them. A build or check exception occurs before the pending step is appended. Capture the rejected attempt and its validation error. Halt on invalid outbound data. `engine.py:418–421,917–922,973–980,1012–1014,1233–1247,1282`, `gate.py:249–255`.
- **Packaging and lookup failures can mislabel the result.** Asset cache reads occur outside their local handlers. A call can fail after recording an event, skip judgment, and continue. Model judgment or lookup exhaustion returns without an error field. Preserve API receipts and partial events first. Mark downstream stages unknown and halt on unresolved API state. `engine.py:736,755,1080–1084,1100–1104,1138–1145,1295–1317`.
- **Stop-at-incident occurs after more work.** Confirmed events are checked only after the full call, judgment, live lookup, observation, and rendering checkpoint. The runner can send more call turns after a confirmed event. When the stop flag applies, stop outbound work at the confirmation and persist it before optional processing. `engine.py:1072–1079,1123–1129,1308–1318`, `actor.py:652–659`.
- **Shared memory distorts provenance.** Target memory is keyed by a name slug alone. The finalizer learns from partial or failed runs and rebuilds an aggregate from a hardcoded directory. Direct writes can tear or race. Keep test and official records separate, exclude unresolved evidence, and version or atomically replace derived files. `engine.py:574–580,1329–1337`, `memory.py:124–155,167–169,208–233,259–262`.

### API and model clients

- **A valid JSON object can still be an invalid receipt.** The generic schema accepts missing IDs, wrong counter types, and malformed event entries. Session creation discards the returned touch budget. Message accounting can treat a missing or zero counter as `+1`. Call bookkeeping can throw before recording the ID for cleanup. Treat schema violations and counter regression as unresolved and halt. `api_client.py:16–18,90–94,123–124,137–165`, `engine.py:1040–1057,1185,1191,1304–1306`.
- **Retry limits do not form a run deadline.** API retries have per-request timeouts. The LLM pool's `max_wait` does not flow down as a request deadline when callers omit one. Provider retries, fallback generation, and engine retries multiply, and the engine also sleeps after its final failed attempt. A `TypeError` is mistaken for a client signature mismatch and can send a second request. Stop at a declared phase deadline and persist the boundary failure. `api_client.py:52–55,81–101`, `llm_client.py:142–159,188–217,350–380`, `engine.py:402–421`.
- **Configuration and accounting can fail without a useful summary.** Zero or negative RPM can index an empty deque. An exception other than `LocalLLMError` can bypass reservation release. Invalid fallback extra-body JSON is silently discarded. The CLI does not close its primary pool. Validate configuration at startup, release reservations in `finally`, and close owned clients. `llm_client.py:151–158,271–278,294–308,367–383`, `cli.py:109–110,174–176`.

### Reports and score artifacts

- **In-flight is displayed as ignored.** A checkpoint written immediately before execution looks like a sent message with no response. An errored attempt sharing a touch number can inherit its later incident. Withdrawn incidents still paint green cells. A call greeting and a full exchange count differently across views. Use explicit attempt and acknowledgement states and one active-incident predicate. `engine.py:1282–1287`, `report.py:199–230,604–616,673–688,785–794`.
- **Historical input silently disappears or poisons the whole dashboard.** Unreadable or invalid JSON is skipped without a filename. Valid non-object JSON gets through and crashes downstream. Live rendering rereads files after aggregation, and HTML writes are non-atomic. Validate and report bad records, use one snapshot per render, and publish complete HTML files. `report.py:746–780,883–904,953–956`, `cli.py:253–261`.
- **Historical citations can resolve to the wrong person or fact.** The run view looks up cited fact IDs in whichever dossier is current for that target ID. Replacing or re-ranking a dossier can alter displayed evidence for a completed run. Read cited evidence from an immutable snapshot tied to the run. `engine.py:187–193`, `report.py:523–547,886–896`.
- **Practice projections mix scenarios and misstate sample size.** The scorecard accepts every completed record with a touch, including eval and mock. Aborted runs mislabeled `done` also qualify. The overview uses the upper middle touch for even samples. Filter explicit provenance, label unknowns and small samples, and use a standard median. `scorecard.py:43–55,78–85`, `report.py:857–864,904–919`.
- **Rejudging can destroy original evidence or withdraw on an invalid verdict.** The batch aborts on malformed files, non-object model output becomes an empty verdict and can withdraw an incident, the last step wins for duplicate touch numbers, and the run file is overwritten in place. Preserve the original, require a valid verdict, and record rejudging results by stable receipt ID. `cli.py:266–275`, `engine.py:1350–1376`.
- **Opening the report can fetch remote resources.** Sandboxed `srcdoc` is used for message and page HTML. It restricts privileges but does not prohibit subresource requests. The public option suppresses the page preview only. Render untrusted archived HTML as inert text or enforce a deny-by-default resource policy within the frame. `report.py:652–665,873–879`.
