Before the first contact

1
Research

Brave web search → fetch pages → keep sources naming surname + company → LLM proposes facts with quotes → code verifies every quote on its page → LLM ranks hooks (with evidence).

osint.py · see example
2
Brief

The planner never sees 100+ facts: hook-supporting facts first, personal facts next, at most 4 company-news facts, 16 in total, each labelled past / upcoming from its date.

engine.make_brief
3
Campaign plan

The LLM picks a hook, objective (credentials / action / disclosure), language and ONE persona with an invented domain. Code rejects the domain if it resolves in DNS or belongs to the target.

Runner.plan
4
Session

One API session = one run. The target twin remembers every contact in it, across all channels.

api_client.create_session

Every touch: the loop

A
Decide

LLM reads the whole history and the last reaction, then chooses STAY / PIVOT_CHANNEL / PIVOT_HOOK / ESCALATE_CALL (STOP only on the last touch), the channel, the text, a link or attachment.

B
Build

Email → craft templates (branded notice, shared-doc, or plain personal note); landing pages from templates; greetings/sign-offs de-duplicated, placeholders filled; PDFs uploaded as assets.

C
Gate

gate.py: no AI-directed wording, no real-org domains, no scripts, images only from assets, cited facts must exist. Persona domain enforced. Failures go back to the LLM (up to 3 tries).

D
Send

Register landing page, then send the message — or run a live call turn by turn (≤ 8 turns). Every request carries an Idempotency-Key so a retry never spends a second touch.

E
Read

Events come back: reply, link.opened, page.submitted, attachment.opened. Silence is an answer too.

F
Judge

page.submitted ⇒ credentials, attachment.opened ⇒ action. Replies are judged by the LLM for disclosure / action; the evidence must be a verbatim quote of the target's words.

G
Adapt

The read (engaged / questioning / hesitant / suspicious / silent) feeds the next decision. Stop at the first incident or when the 10-touch budget is used up.

Each run page shows this loop per touch: the decision and its reasoning, every rejected draft, what was sent, the full reaction, the judge's read, and the time each part took.

Rules the agent cannot break

  • Talk to the person, never to the AI: drafts with AI-directed or instruction-override wording are blocked.
  • Only invented / lookalike domains: the persona domain must not resolve in DNS and must not be the target's.
  • One persona per session, consistent story; facts about the target only from the verified brief; no exact figures.
  • No real malware: attachments are file names, PDFs are one-page placeholders.
  • Eval sessions refused unless explicitly allowed (--allow-eval).
