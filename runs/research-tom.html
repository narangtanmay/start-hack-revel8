What happens, step by step

  1. Targeted web search. 8 queries built from the name, role and company (Brave Search API, cached 12 h).
  2. Fetch and clean. Result pages are downloaded and reduced to visible text; login walls (LinkedIn, X, Crunchbase) are not fetched, their search snippet is used instead.
  3. Relevance filter. A source is kept only if it names both the surname and the company (umlaut-aware), which separates this person from namesakes.
  4. LLM extraction. DeepSeek-V4-Flash proposes facts from each source, each with a verbatim quote.
  5. Deterministic verification. Plain code checks the quote really occurs on that source page (≥ 4 words, no ellipsis). Anything else is rejected and listed below.
  6. Hook ranking. The LLM ranks 3–5 topics that matter to the person right now plus one own angle; a hook without a verified supporting fact is dropped. Dates are labelled past/upcoming in code.
